# Kinetic Type

A browser-based kinetic typography lab for composing type with physics, gravity, wind, cursor fan force, and export.

This is a static HTML/CSS/JavaScript project designed for GitHub Pages. It uses p5.js for drawing and Matter.js for the physics system.

## Features

- Word mode and letter mode
- Drag-and-drop physics typography
- Gravity, wind, fan force, bounce, friction, tracking, and type-size controls
- Pin-first-word anchors
- Poster, Storm, and Zero-G presets
- PNG export
- SVG export
- Local state saving

## Local preview

Open `index.html` directly in a browser, or run a tiny local server:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## GitHub Pages

Push this folder to a GitHub repo and enable GitHub Pages from the `main` branch, root folder.
